# 如何用上 Codex 

> Codex 未对中国大陆开放服务，国内既无法直接注册支付，也无法直连访问。本教程是一种可用方式：**通过外区（土耳其）Apple ID + 礼品卡在 iOS 端订阅 ChatGPT Plus，从而获得 Codex 使用权限**。这种方式我觉得要比在中转站购买要安全的多。当然**前提是你要有一个稳定的 VPN 工具 和 iPhone**，具体如何获取 VPN 这里就不介绍了。

> 本教程中的方式是我目前在用。因为会涉及到付款操作，是否使用请自行判断。

## 整体思路

很多人卡在「付不了钱」这一步：国内的信用卡 / 支付宝无法直接给 OpenAI 付款，OpenAI 本身也不接受中国大陆用户。绕过的方式是借道 iOS：

1. 注册一个**外区 Apple ID**（这里选土耳其区, 购买套装的价格相对便宜）
2. 在 App Store 下载 ChatGPT App
3. 用**土耳其礼品卡**给 Apple ID 充值
4. 手机挂上VPN（可以从 apple store 上下载一个 Shadowrocket,）
4. 在 ChatGPT App 内用 Apple 内购订阅 **Plus**

下面逐步说明。

## 第一步：注册一个外区 Apple ID

用 Google 邮箱（Gmail）注册一个新的 Apple ID，地区先随意。

**关于手机号：** 一个手机号如果已经绑定过其他 Apple ID，在新 Apple ID 的验证环节可能不通过。我的解决办法是换了一个没绑定过的手机号。如果遇到一直验证失败，多半是这个原因。

## 第二步：把 Apple ID 地区改为土耳其

登录 [account.apple.com](https://account.apple.com/)，修改账号的**国家或地区**以及**账单地址**。

- **为什么选土耳其？** App Store 按地区定价，土耳其区的订阅价格折算后通常比美区便宜不少，礼品卡也相对好买。
- **账单地址必须是土耳其地址**，因为 ChatGPT 不对中国开放，地址选在国内会无法订阅。地址可以在豆包等工具里搜一个真实的土耳其地址填入。

## 第三步：在 iPhone 上下载 ChatGPT

在 iPhone 的 **App Store** 中登录这个新的土耳其 Apple ID，搜索并下载 **ChatGPT**, 如果手机上没有连接 VPN 的工具，再下载一个**Shadowrocket**（熟称：小火箭）。


## 第四步：给 Apple ID 充值土耳其礼品卡

由于地区选的是土耳其，充值货币是土耳其里拉（TRY）。比较常见的方式是在**闲鱼 / 淘宝**上购买土耳其区 Apple 礼品卡，把卡密充到这个 Apple 账号里。(注：选销量高的，价格相对便宜的就行，chatGPT plus 套餐需要人民币大概150￥左右的土耳其里拉，可以先尝试充个一块钱验证下是否正常充值)

## 第五步：在 ChatGPT App 内订阅 Plus

打开 ChatGPT App，在会员页选择 **Plus 套餐**，支付方式选择 **通过 Apple 订阅（Apple 内购）**，扣的就是第四步充进账号的金额。

> **关于价格：** 通过 Apple 内购订阅会比官网直接订阅贵约 30%（苹果抽成），这是 iOS 渠道的代价。

## 第六步：配置网络访问（关键，常被忽略）

**光有 Plus 订阅是不够的。** OpenAI 的服务器在国内无法直连，无论是网页版 chatgpt.com 还是 Codex，都需要稳定的网络代理（代理节点需落地在 OpenAI 支持的地区）才能访问。

- 没有这一步，订阅再成功也打不开 ChatGPT / Codex。
- 节点落地地区要避开 OpenAI 明确不支持的地区，否则可能触发风控。

## 第七步：使用 Codex

完成以上步骤后：

- 你的 ChatGPT 账号已是 **Plus 会员**，网页 / App 内可正常使用。
- 在 [chatgpt.com/codex](https://chatgpt.com/codex) 或通过**Codex**。

## 常见问题

- **续费：** Plus 每月自动通过 Apple 扣费，只要 Apple 账号内余额充足即可；余额不足会暂停订阅。
