## 什么是 [QClaw](https://qclaw.qq.com/index.html)



> QClaw 是腾讯电脑管家基于 [OpenClaw](https://openclaw.ai/)("小龙虾") 开源框架打造的本地化 AI Agent 助手，属于 “小龙虾" 类的AI应用，通过内置不同的 AI 模型， 可以高效方便的做各种事情。



## 为什么写 QClaw 系列探索文章



1. 目前工作主要是做 OpenClaw 类的应用开发，在学习和研究 OpenClaw 相关技术，QClaw 作为竞品，有学习和参考的意义。

2. 我在研究 QClaw 时发现他们的核心实现依赖库（qclaw-plugin）没有做混淆压缩，机会难得（0.2.5 以上代码已经压缩混淆了）。
